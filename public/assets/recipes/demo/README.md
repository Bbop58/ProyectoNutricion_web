# Imágenes ilustrativas de recetas demo

32 imágenes generadas con la herramienta ImageGen el 24/11/2026, una por receta del catálogo demo de NutriSalud. Representan sus ingredientes y preparación; no son fotografías de platos reales de las empresas.

Archivos WebP optimizados para tarjetas web y móvil, con lado máximo de 640 px. Los originales se conservan fuera del repositorio. `manifest.json` registra tamaño y SHA-256 de cada archivo.

Las mismas recetas de Equilibrio, Andina y Vitalia reutilizan su imagen correspondiente. Las URLs públicas se guardan en `recipes.image_url`. La carga de imágenes no sustituye fotos cargadas manualmente ni modifica la prescripción, los ingredientes o los nutrientes.
